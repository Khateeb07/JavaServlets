## 📌 About

A hands-on repository containing implementations of core **Java Servlet** and **JSP** concepts built while learning Java EE web development.

This repository focuses on understanding:
- Servlet architecture
- Session management
- Request handling
- JDBC integration
- JSP-Servlet interaction

through practical implementation of individual concepts.

---

# 🚀 Concepts Covered

- ServletConfig & ServletContext
- HTTP Sessions
- Cookies
- Hidden Form Fields
- URL Rewriting
- RequestDispatcher
- sendRedirect()
- JSP Integration
- JDBC Connectivity
- DAO Pattern
